# CCC_城市速寫工作坊_鐵皮街屋篇

以鐵皮街屋表面的風化質感為靈感，透過隨機色票、垂直條狀結構與密集點陣，模擬鐵鏽、褪色油漆與金屬磨損的層次。每次重新整理都會隨機選擇不同色票，因此同一份程式可以產生不同的畫面氣氛。

![image-01](image/image-01.png)
![image-02](image/image-02.png)
![image-03](image/image-03.png)

* 本 repo 為 tutorial 1、tutorial 2、tutorial 3 的範例程式，請搭配 openprocessing tutorials 使用。*
* 投影片：https://github.com/ccc-2026-summer/ccc-materials/tree/main/L1-L2

## Tutorial 1: 以細小、重複的形狀鋪陳鐵皮表面，練習用規律與隨機交錯出層次。

![basic](image/basic.gif)


中文教學：https://openprocessing.org/@u176241/2983310

內容：

- 使用 `function` 整理繪圖流程，練習模組化概念
- 使用 `for` 迴圈建立重複圖形，理解規律排列
- 透過 `coordinate and transform` 控制位置與比例
- 結合 `random()` 讓畫面保有變化與不規則感
- 使用 `array and color` 管理色票與配色關係
- 搭配 `sin` 與 `color mode HSB` 建立明暗層次
- 運用 `map function` 製作漸層與消散效果
- 加入 `shape` 細節，強化材質與表面質感

## Tutorial 2: Layout study，從 T1 的矩形排列延伸，進一步觀察浪板結構的節奏與光影摺痕。

![layout](image/image-layout.png)


中文教學：https://openprocessing.org/@u176241/2983360

內容：

- 練習觀察生活周遭的鐵皮排列方式
- 觀察座標與長寬變化的規律
- 嘗試修改參數延伸更多變化

## Tutorial 3: 加入 `noise` 製作有機的鐵鏽擴散與凹陷處生鏽的效果。

![noise](image/image-noise.png)

中文教學：https://openprocessing.org/@u176241/2983623

內容：

- 使用 `noise` 函數繪製有機感的擴散鐵鏽
- 使用 `noise` 搭配 `sin` 函數，繪製出亮線與鐵鏽交錯的效果

## CCC Urban Sketch Workshop: Tin House Street Houses

## Tutorial 1: Basic

Description: Use small, repeated shapes to build the tin surface and practice layering regularity with variation.
![basic](image/basic.gif)


EN version: https://openprocessing.org/@u176241/2983362

Content:

- Use `function` to organize the drawing flow and practice modular thinking
- Use `for` loops to build repeated forms and understand regular patterns
- Use `coordinate and transform` to control position and scale
- Combine `random()` to keep the image varied and irregular
- Use `array and color` to manage palettes and color relationships
- Use `sin` and `color mode HSB` to create tonal variation
- Use `map function` to make gradient and fading effects
- Add `shape` details to strengthen material and surface texture

## Tutorial 2: Layout study

Description: Extend the rectangle layout from T1 and study the rhythm of corrugated sheets and their folded light and shadow.

![layout](image/image-layout.png)



EN version: https://openprocessing.org/@u176241/2983604

Content:

- Practice observing how tin sheets are arranged in everyday life
- Study the patterns of coordinates and width/height changes
- Try adjusting parameters to create more variations

## Tutorial 3: Noise

Description: Add `noise` to create organic rust spreading and the effect of rust forming in recessed areas.

![noise](image/image-noise.png)

EN version: https://openprocessing.org/@u176241/2983620

Content:

- Use `noise` to draw organic, spreading rust textures
- Combine `noise` with `sin` to create alternating highlights and rust lines
